# 刘航视觉设计作品集

基于 React 和 Vite 构建的个人简历与视觉设计作品集。

## 本地开发

```bash
npm install
npm run dev
```

## 构建与检查

```bash
npm run lint
npm run build
```

生产构建输出到 `docs` 目录，用于 Gitee Pages 静态部署。

## Gitee Pages

在仓库的 Gitee Pages 设置中选择：

- 部署分支：`master`
- 部署目录：`docs`

每次更新代码后重新运行 `npm run build`，提交并推送 `docs` 目录，然后在 Gitee Pages 中点击更新。
